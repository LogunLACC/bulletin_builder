## Technical Decisions & Patterns

### Version Storage Format
```
user_drafts/
├── ClubLife_20251010.json          # Main draft
└── versions/
    └── ClubLife_20251010/           # Per-draft versions
        ├── ClubLife_20251010_v20251010_163045_123456.json
        ├── ClubLife_20251010_v20251010_163045_123456.json.meta.json
        └── ... (up to 20 most recent)
```

### Metadata Structure
```json
{
  "version_id": "20251010_163045_123456",
  "parent_draft": "ClubLife_20251010.json",
  "timestamp": "2025-10-10T16:30:45.123456",
  "description": "Before adding events",
  "auto_created": false,
  "sections_count": 3,
  "file_size": 12345,
  "version_path": "/path/to/version.json"
}
```
